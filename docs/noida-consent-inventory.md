## Decisions needed before production

1. Approve exact disclosure text and stable disclosure-version IDs per purpose and language.
2. Decide whether marketing consent is separate and optional from enquiry-response consent. Existing Estate 1, Estate 2, Dholera Estates, and Industrial wording combines purposes; Industrial also has a marketing-only page.
3. Approve how popup/side/property-card/site forms without visible consent controls should capture an affirmative action. Current `consent: true` adapter values must not be treated as evidence of user choice.
4. Approve whether central storage must retain a disclosure snapshot/hash and the affirmative response/channel in addition to the existing timestamp/version marker.

Until these decisions and the resulting browser tests are complete, consent evidence is not production-ready across all five websites. Preserve current public forms unchanged pending owner/legal review.
